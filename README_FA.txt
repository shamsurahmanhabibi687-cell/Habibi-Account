Habibi Accounting – نسخه آغازین آزمایشی

این پروژه یک نمونه اولیه وب‌اپلیکیشن قابل نصب روی اندروید (PWA) است.
امکانات فعال در این نسخه:
- داشبورد اولیه
- ثبت ساده فروش، خرید و مصارف
- ذخیره محلی اطلاعات در مرورگر با IndexedDB
- تهیه فایل پشتیبان JSON
- پوسته آفلاین پس از بارگذاری و کش اولیه

محدودیت‌های مهم:
- این نسخه هنوز نرم‌افزار کامل حسابداری و هم‌سطح QuickBooks نیست.
- بخش اجناس، مشتریان، تأمین‌کنندگان، دفتر کل، سند حسابداری، تراز آزمایشی،
  سود و زیان، بیلانس شیت، فاکتور چاپی و گزارش‌های کامل هنوز ساخته نشده‌اند.
- داده‌ها فقط در همان دستگاه/مرورگر ذخیره می‌شوند؛ پاک‌کردن داده‌های مرورگر
  می‌تواند باعث از بین رفتن اطلاعات شود. همیشه پشتیبان بگیرید.
- برای نصب PWA معمولاً باید پروژه یک‌بار از طریق یک نشانی HTTPS باز شود؛
  سپس در Chrome گزینه Install app یا Add to Home screen انتخاب گردد.

گام بعدی توسعه:
1. تکمیل دفتر حساب‌ها و ثبت دوطرفه (Double-entry accounting)
2. مشتریان و تأمین‌کنندگان با مانده افتتاحیه
3. انبار و گردش موجودی
4. فاکتور فروش/خرید و چاپ
5. گزارش‌های مالی و بستن دوره
6. ورود امن، قفل برنامه و بازیابی پشتیبان
